# 🇵🇰 Pakistan Travel Express

Pakistan Travel Express is a console-based ticket booking system developed in **C++**. The application allows users to book tickets for **cars, buses, and domestic flights**, select routes between major Pakistani cities, choose travel classes, reserve seats, calculate fares dynamically, process payments, and manage bookings through an interactive menu-driven interface.

## ✨ Features

* Multi-transport booking (Car, Bus & Aeroplane)
* Interactive seat selection with seat map visualization
* Route selection between major cities of Pakistan
* Dynamic fare calculation based on travel distance
* Economy, Executive, Premium AC and Business classes
* Child and Senior Citizen discounts
* Multiple payment methods
* Boarding pass generation
* Ticket cancellation with seat release
* Session summary and earnings tracking

## 🛠 Technologies Used

* C++
* Arrays
* Functions
* Strings
* Loops
* Switch Case
* Conditional Statements
* Console-Based UI

This project was developed to strengthen my understanding of procedural programming, modular design, data handling, and real-world problem-solving using C++.
