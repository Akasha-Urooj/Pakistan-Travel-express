🚀 Excited to share one of my biggest C++ projects!

I recently developed **Pakistan Travel Express**, a console-based ticket booking system built entirely in **C++**.

The goal of this project was to move beyond basic programming exercises and build a larger application that simulates a real-world travel booking experience.

### Key Features:

✈️ Car, Bus & Domestic Flight Booking

🗺️ Route selection between major cities of Pakistan

💺 Interactive seat selection

💰 Dynamic fare calculation based on travel distance

🎟️ Boarding pass generation

💳 Multiple payment methods

👶 Child & Senior Citizen discounts

❌ Ticket cancellation with seat release

📊 Session summary and earnings tracking
